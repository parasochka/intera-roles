Concepts and terminology

Nine words carry the whole model. Everything on a dashboard is one of them.

Updated 2026-08-13 v0.003 4 min read

Metric

A watched number inside a role. A Metric knows its source, its refresh window, its trend and its threshold — and it carries an explicit data status, so a stale value never reads as a good value. Called KPI before v0.003.

metrics.trendmetrics.thresholdmetrics.dataStatus

Event

Something important changed. An Event records the value before and after, the source system and the time — the raw material for everything below.

Reconciliation

A continuous comparison between things that should agree: two systems, two periods, or a system and a business rule. The result is not a percentage — it is the list of records that differ.

4,812 records differ by more than 0.5%

Incident

Something requires attention and action. An Incident has an owner, a priority, an expected time to impact and the evidence that produced it. It is tracked until it is closed.

Pattern

What keeps happening, and under which conditions. Patterns are found in Pattern Studio and can be promoted into permanent checks.

Role

A ready-made module built around a real responsibility, holding its own Metrics, Reconciliations, dashboards and detection logic. Roles are configuration, not code.

DataSource

One read-only connection to one system: what is read, which fields are mapped, how often. This is the unit IT is asked for — nothing broader.

Asset and Asset Type

The thing being watched — a vessel, a customer, a contract, a network element. Asset Types define which attributes exist and which Metrics can attach to them.

Market package

A reusable bundle for one industry: roles, checks, asset types and integrations. Partners build them; customers deploy them and adapt the logic.

KPI is now Metric across the product and the docs. Existing roles were migrated automatically; saved dashboards keep working.
