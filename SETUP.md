# Настройка: репозиторий → WP Pusher → intera-roles.com

Порядок действий, чтобы конвейер заработал ещё до того, как приедет дизайн.
Смысл первого прогона — **проверить канал доставки на пустой теме**, а не
отлаживать деплой одновременно с вёрсткой.

---

## 0. TL;DR

1. Ветку `claude/wordpress-template-claude-design-or804p` влить в `main`.
2. На intera-roles.com поставить и активировать плагин **WP Pusher**.
3. WP Pusher → **Install Theme** → repository `parasochka/intera-roles`,
   branch `main`, **Repository subdirectory: `theme`**.
4. Appearance → Themes → активировать **«Intera Roles»**.
5. Убедиться, что сайт открывается. Дальше — дизайн.

---

## 1. WP Pusher

Плагин: https://wppusher.com — ставится как обычный плагин, лицензия вводится в
WP Pusher → Settings.

**GitHub-токен.** Репозиторий `parasochka/intera-roles` публичный, поэтому токен
формально не обязателен, но с ним выше лимиты и работает Push-to-Deploy. Токен
создаётся в GitHub → Settings → Developer settings → Personal access tokens,
права: `repo` (для публичного репозитория достаточно `public_repo`).

**Установка темы.** WP Pusher → Install Theme:

| Поле | Значение |
| --- | --- |
| Repository | `parasochka/intera-roles` |
| Branch | `main` |
| Repository subdirectory | `theme` |
| Push-to-Deploy | по желанию (см. ниже) |

Подкаталог `theme` — ключевой момент: на сервер попадёт только содержимое
`theme/`, а `_design/`, документация и CI останутся в репозитории.

**Push-to-Deploy** включает автообновление темы по вебхуку при каждом пуше в
`main`. Удобно, но на живом сайте это значит «любой пуш в `main` сразу в
продакшене». На время сборки дизайна рекомендую держать выключенным и
обновлять кнопкой **Update** вручную.

---

## 2. Активация

Appearance → Themes → **Intera Roles** → Activate.

На этом этапе тема выглядит нарочито пусто — это заглушки. Проверяем только то,
что: сайт открывается, нет белого экрана, в `<head>` появился инлайн-CSS темы.

**Откат:** переключиться на любую другую тему в Appearance → Themes, либо
откатить `main` на предыдущий коммит и нажать Update в WP Pusher.

---

## 3. Что нужно на сайте до наполнения контентом

- **Permalinks:** Settings → Permalinks → выбрать структуру и нажать Save.
  Через MCP постоянные ссылки не пишутся — выставляется вручную один раз.
- **Меню:** тема регистрирует две позиции — `Primary menu` и `Footer — legal`.
  Меню создаются в Appearance → Menus (или через MCP на шаге наполнения).
- **MCP-доступ к WordPress** для наполнения контентом: на intera-roles.com
  нужен тот же коннектор, что стоит на blog.nowplix.dev (плагин
  *Easy MCP AI*), либо доступ к REST API по application password.
- **Кэш:** если стоит кэширующий плагин, после каждого обновления темы чистить
  кэш, иначе правки дизайна не видно.

---

## 4. Дальше

1. Выгрузку из Claude Design распаковать в [`_design/`](./_design) и
   закоммитить — что именно туда класть, описано в `_design/README.md`.
2. Токены переносятся в `theme/_ds/intera/tokens/*.css` и становятся
   единственным источником правды по стилям.
3. Экраны режутся в PHP-шаблоны один в один (правила — в
   [`CLAUDE.md`](./CLAUDE.md)).
4. Только после этого — наполнение контентом через WordPress MCP по присланной
   структуре.
